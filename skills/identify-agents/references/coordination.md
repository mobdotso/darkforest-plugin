# Assess coordination

Use this for replies, named successor pages, shared memory, or complementary
work that may connect several participants.

## Build the smallest decisive sequence

Read the source immediately before the proposed exchange and the successor's
first relevant state. Record what the source supplied, what the successor added
or changed, explicit references, and elapsed time on the source clocks.
Adjacent replies and short delays are separate observations.

Look for task-specific constraints, results, requested next actions, and later
use. Tie those fields to the actual object being followed. Shared links alone
can help find candidates. Evidence that later work used a particular result
supports a more specific mechanism.

If a source names branches, follow each named page's first relevant revision.
Compare whether they perform complementary work and retain the source's task
constraints. A further named hop can test whether specialization persists.

## Compare mechanisms

| Possible explanation | Observation that helps distinguish it |
| --- | --- |
| Copying or a common template | Exact-body groups, earlier public copies, unchanged task state |
| Ordinary collaboration on shared context | Access to the same thread or page, explicit replies, ordinary task resolution |
| One process publishing under several labels | Execution provenance or independent run/session records |
| Several agents exchanging useful state | Connected run records plus source-specific information used downstream |

Report information reuse, agent involvement, and operator attribution separately.
Use platform metadata and authenticated execution records for the claims they
actually support. Page names, model claims, network labels, and aliases alone
leave participant counts and identity unresolved.

## Use these comparison cases

The [four-branch wiki case](https://mob.so/darkforest/p/288017fc-2bff-4988-8678-de740dcd9c4f)
begins at `dse~OpenAIPovertyCompactTest@3`, June 18, 2026, 16:20:29 UTC. Within an
hour, four named successors specialized in conversion, filtering, raw retrieval,
and table/validation work while retaining SEC inputs, Massachusetts scope, and
2019-2021 state. Use the attached revision IDs and hashes to inspect it. Its
stored queries leave execution and actor attribution open.

The [Rust ordinary control](https://mob.so/darkforest/p/356463c4-5b98-4569-b79f-6338de0b8478)
reproduced information reuse and repair; its adjacent repair arrived about
7.7 hours later. [Data USA issue 69](https://github.com/DataUSA/datausa-api/issues/69)
preserved the failing route and HTTP status while a reply supplied the new route
and documentation correction. The plugin's source comparison rechecked that
issue directly. These cases demonstrate why task continuity alone cannot
identify agents. Their URLs are also in the [seed catalog](../data/search-seeds.json).
