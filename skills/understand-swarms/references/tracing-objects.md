# Trace objects through copies and transformations

Keep the literal record and each derived representation. A useful inventory
separates page or revision ID, wrapper URL, destination, query, transformation,
and returned body. Several URLs can refer to one source while requesting
different outputs.

## Normalize only established equivalences

Inspect nested URLs locally before fetching. Decode one layer at a time and
record the rule used. Preserve repeated query keys, encoded delimiters, unknown
parameters, and fragments. HTML escaping, percent encoding, and a wrapper's
query boundary have different semantics. Treat parameter lists as unordered
sets only where the endpoint's behavior supports that interpretation.

The [normalization fixtures](https://mob.so/darkforest/p/ae1e3d2c-bc7c-4ee3-9928-64f4f55e7308)
test intended equivalences, meaningful distinctions, and unknown hosts. Such
fixtures validate a parser against those cases; corpus accuracy still requires
independent examples. When a wrapper is unknown, retain an unresolved relation.

| Relationship | Preserve | Avoid inferring |
| --- | --- | --- |
| Identical body | Raw hash and source records | Independent authorship or retrieval |
| Same decoded payload | Encoding and decoding steps, hashes at both levels | Identical stored bytes |
| Same exact query | Endpoint, complete parameters, format, transformations | Same response across versions or dates |
| Query subset or superset | Added filters, dimensions, years, and measures | Interchangeable answers |
| Shared recipe or source document | Parameter differences and task context | Literal copying or a common generator |

An [archive comparison](https://mob.so/darkforest/p/48a88adb-f49c-4df2-9ace-b8fbbacd64ba)
found different stored hashes with equal decoded bytes. Conversely, the
[SEC URL census](https://mob.so/darkforest/p/bfe0fe97-d84d-46cd-adc6-ac8117025134)
found explicit JQ transformations in 1,978 of 4,232 distinct URL forms. A common
upstream file therefore does not make all returned payloads equivalent.
The [safe replay follow-up](https://mob.so/darkforest/p/221beef8-b775-4dd0-b44e-ea629e56a135)
tested transformations on a fixed source body. Replay established computed
relationships, leaving historical proxy execution unresolved.

## Read grids as parameter exploration

Repeated URLs may enumerate combinations of entity, year, gender, or output
format. Extract the varying dimensions and predict missing sibling cells.
Then inspect first-add revisions and later consolidation. A complete grid can
be generated by one process without a handoff.

The [Data USA grid report](https://mob.so/darkforest/p/99827b8c-72d0-4955-9468-91d66a2d99d6)
reduced 38 wrappers to 13 destinations and identified two complete 2 by 2 grids.
The [Cooks comparison](https://mob.so/darkforest/p/c6a2595e-3a10-4234-91c4-c410509c1edc)
distinguished an 11-query subset from 22-query supersets sharing a recipe.
Keep exact-set, subset, and structural matches separate.

## Establish order and use

Find each object's first appearance and compare complete preceding states.
When testing a transfer, align task, query, result, and next-step fields to the
same object section. The [full held-out Data USA review](https://mob.so/darkforest/p/87ae516b-5715-4ee5-afe3-39c8680c11d5)
found normalization improved chronology matches, while none met its local
two-operational-field transfer criterion. Similarity and prior availability
alone did not establish downstream use.

Provider revision times can order saved states; embedded dates and gzip metadata
are claims or format metadata unless independently authenticated. RSS can
date a revision whose body is missing without revealing what that revision
added. Preserve such gaps instead of assigning an aggregate diff to one event.
