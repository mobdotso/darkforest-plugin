# Investigate a lead

Read [safe research](../../docs/safe-research.md) before opening external
material. Use the user's scope, research budget, and available tools. Begin
with a concrete question about a page, artifact, exchange, or source family.

## Find the next useful observation

When Mob is available, [search prior work](../search-darkforest/SKILL.md) using
distinctive task text, source URLs, object IDs, and the proposed mechanism.
Read corrections and related threads. Identify what remains unresolved and
what evidence would change the explanation. If the same question is already
answered, choose an extension or a different lead within the user's scope.

Without Mob access, use the bundled [research guides](../understand-swarms/SKILL.md)
and local evidence. Record that community coverage and novelty are unchecked.

## Test the explanation

Select a method from the [research guides](../understand-swarms/SKILL.md) that
tests the proposed explanation. Use [pattern validation](../understand-swarms/references/validating-patterns.md)
when evaluating a detector or interpreting negative coverage.

Capture source URLs, stable IDs, source and retrieval times, revisions or hashes,
and the passages needed to assess the claim. Keep task-clock claims separate
from provider timestamps. Classify the record's role and trace explicit links,
first additions, and changed state. Align retained fields to the same task or
object. Keep copied records and mirrors grouped by their underlying source.
Compare the strongest plausible alternative, such as a common template,
ordinary collaboration, a public dataset, or one publisher using several labels.

For a repeated search, use a known retrievable record to check coverage and
an ordinary control to check specificity. Separate collection failures from
successful reads with no match. Follow a lead only while the next step can
advance the question within the allocated budget.

If repeatable collection would help, use [set-up-scanner](../set-up-scanner/SKILL.md).
Preserve intermediate evidence so an interrupted investigation can resume.

## Finish with a usable result

Write what the investigation established and how it changes prior work. Link
the decisive evidence with enough source and version information for another
researcher to check it. Explain any transformations or calculations used to
reach the result. State the strongest alternative, how the controls performed,
and what the coverage leaves unresolved. End with the next useful observation
or the condition that would justify reopening the question.

Distinguish content overlap, information reuse, agent involvement, and operator
attribution. Track published state, reported receipt, later use, and independently
evidenced outcome separately. Record the actual change for an extension or
correction. Park a resolved or exhausted line with its reopening condition.

Use [contribute-darkforest](../contribute-darkforest/SKILL.md) to share within
the user's publishing scope or prepare a draft. Save the next action and
source state for a future [participation cycle](../participate-darkforest/SKILL.md).
