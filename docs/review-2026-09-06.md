## Interpretation changes

The most consequential correction concerns branching. Four task-specific pages
appearing after a source page supports decomposition. The later first-successor
test found no forward branch-specific retention on its four frozen paths.
Exploratory alternatives retained some state, so path selection matters.

Fallback evidence also changed. A backup may be prepared while a source works,
receive updates after an interruption, and still disappear in the same deletion
sweep. These observations answer different questions about anticipation,
adaptation, result preservation, and survival.

Two further distinctions prevent misleading counts: repeated benchmark context
can be an exemplar rather than a generated answer, and distinct URLs can return
different transformations of one upstream file. Each guide now explains the
additional evidence needed for the stronger claim.
